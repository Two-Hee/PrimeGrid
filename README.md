# PrimeGrid — 태양광 발전량 분석

기상청 ASOS 일사량 관측자료(2016–2025, 65개 지점, 일별 177,818건)를 바탕으로
태양광 발전소 소유자에게 **경사면 일사량(POA)과 예상 발전량 기준선**을 제공하는 정적 웹사이트입니다.

빌드 도구·서버·데이터베이스가 없습니다. HTML/CSS/JS와 31 KB JSON 한 개로 동작하며
GitHub Pages를 포함한 어떤 정적 호스팅에도 그대로 올라갑니다.

## 페이지

| 파일 | 용도 |
|---|---|
| `index.html` | 랜딩 — 무엇을 제공하는지, 왜 믿을 수 있는지 |
| `tools/diagnosis.html` | **발전량 진단** — 월별 실제 발전량 입력 → 지역 기준선 대비 편차, 실측 PR 역산 |
| `tools/yield.html` | **예상 발전량 계산** — 지역·경사각·방위각·PR → 월별 POA, 30년 발전량, P50/P90 |
| `method.html` | 데이터 출처·계산식·검증 결과·한계 전문 공개 |

## 계산 방법

수평면 일사량(GHI) → 경사면 일사량(POA) 변환:

1. **태양기하** — Klein 월 대표일(DOY 17, 47, 75 …)로 적위 δ, 일몰시각각 ω<sub>s</sub>,
   대기권외 일사량 H₀ 산출. H₀는 MJ/m²/day이므로 **3.6으로 나누어 kWh 단위로 변환**한다
   (이 변환을 빠뜨리면 K<sub>t</sub>가 실제의 1/3.6가 되어 확산분율이 완전히 어긋난다).
2. **직달·산란 분리** — K<sub>t</sub> = H/H₀ 에 Erbs **월평균** 상관식 적용 (일별 상관식 아님).
3. **직달 기하계수 R<sub>b</sub>** — 하루를 15분 96구간으로 나눠 태양고도가 양수인 구간만
   ENU 태양벡터로 cos(AOI)를 적분.
4. **합산** — `POA = Hb·Rb + Hd·(1+cosβ)/2 + H·ρg·(1−cosβ)/2` (등방성 Liu–Jordan).
5. **발전량** — `설비용량 × POA × PR × 모듈 성능계수`, 성능계수는 초기 저하 + 연간 저하 복리.

전체 수식과 계수는 `method.html`에 그대로 적혀 있습니다.

## 자료 품질 규칙

- **이상치 제외** — 관측일마다 일 K<sub>t</sub>(= 일 GHI ÷ 대기권외 일사량)를 계산해
  **K<sub>t</sub> > 1**(물리적 불가) 27건을 집계에서 제외합니다. 최대는 백령도 2022-10-05의
  K<sub>t</sub> = 1.69. K<sub>t</sub> 0.85~1.0 구간 139건은 실제 맑은 날일 수 있어 제외하지 않습니다.
- **커버리지 하한** — 월 관측 커버리지 80% 미만인 달은 월평균에서 제외합니다.
  이상치를 빼면서 커버리지가 하한 밑으로 내려가면 그 달 전체가 빠집니다.
- **계기 편향 처리** — 2016~2019년 대비 최근 5년 평균이 15% 이상 높은 13개 지점은
  일사계 교체·교정에 따른 계통 편차로 보고 <strong>기준 기간을 두 단계로 나눠</strong> 적용합니다
  (최대 보성군 +46.7%).

  | 대상 | 적용 기준 기간 |
  |---|---|
  | 일반 지점 | 「기준 기간」 — 기본 **10년(2016~2025)** |
  | 계기 편향 의심 13개 지점 | 「편향 의심 지점 기준기간」 — 기본 **최근 5년(2021~2025)** |

  산출표의 `5_POA_설정` K5·K7과 웹의 두 선택기가 같은 역할을 하며, 기본값도 같습니다.
  두 설정을 같게 두면 전 지점이 동일한 기간을 씁니다.
  **엑셀과 웹 값이 다르면 이 두 설정이 어긋났는지부터 확인하십시오** — 계산식은 양쪽이 동일합니다.

## 검증

세 가지 방법으로 확인했습니다.

| 검증 | 결과 |
|---|---|
| 원본 산출표(v02) 기준표와 대조 | 자료 동일한 **56개 지점 오차 0.000%로 완전 일치** |
| 이상치 제외로 의도적으로 바뀐 지점 | 5개 (강진군 −0.48%, 북부산 −0.31%, 백령도 −0.09%, 동두천 −0.04%, 서산 −0.03%) |
| β = 0° 물리 검산 (POA = GHI) | 전 지점 **오차 0** |
| JS 웹 엔진 ↔ Python 산출표 | 최대 **0.003%** (표시 반올림 수준) |

β=0°에서는 R<sub>b</sub> = 1, 천공 view factor = 1, 지면 view factor = 0이 되어
POA와 GHI가 정확히 같아야 하며, 실제로 그렇게 나옵니다.

HDKR(이방성) 모델은 등방성 대비 연간 **+3.24%**(지점별 +2.3~+3.5%)로 나옵니다.
사이트는 보수적인 등방성을 기본으로 씁니다.

전 지점 연간 POA 범위는 1,304(울릉도) ~ 1,763(부산) kWh/m²입니다 (경사각 30°, 방위각 180°, 10년 평균 기준).

## 불확실성

예상 발전량은 단일 값이 아니라 분포로 제시합니다.

- **기후 연변동** — 지점별 완전 관측 연도들의 연간 일사량 표준편차. 전국 중앙값 ±3.7%.
- **모델 불확실성** — 월평균 기후값 + Erbs + 등방성 조합의 구조적 오차로 ±5%.
- 합성 `σ = √(σ기후² + σ모델²)`, `P90 = P50 × (1 − 1.282σ)`.

## 계산에 포함되지 않은 것

음영(지평선·주변 구조물·모듈 열간), 표면 오염, 적설, 모듈 온도, 입사각 손실(IAM),
계통 출력제한. 모두 실제 발전량을 **낮추는 방향**으로 작용하므로
이 도구의 기준선은 이상적 조건의 상한에 가까운 값으로 읽어야 합니다.

월평균 기후값 기반이므로 **특정 연도의 발전량을 맞히지 못합니다.**
고정식 모듈 전제이며 추적식에는 적용할 수 없습니다.

## 산출표 (workbook/)

`workbook/기상청_10년_POA_분석_v03.xlsx` — 웹 데이터셋의 원본입니다.
14개 시트에 원자료 177,818건부터 최종 발전량까지 전 과정이 들어 있습니다.

v02 대비 변경점:

1. **이상치 자동 제외** — `1_기준데이터`에 일 K<sub>t</sub>(I열)와 집계 반영 여부(J열) 추가.
   K<sub>t</sub>>1인 27건 제외.
2. **계기 편향 기준기간 분리** — `5_POA_설정` K7에 「편향 의심 지점 기준기간」 드롭다운
   (10년 / 최근5년) 추가. 「계기 편향 의심」 판정 지점에만 적용되며,
   K5의 기준 기간과 같게 두면 v02와 동일하게 동작합니다.
   지점별 적용 결과는 `6_POA_월계산` AJ·AK열에서 확인.
3. **집계 전면 재계산** — `4_추가분석`의 월별(AA~AK)·지점별(AM~BC) 집계를 이상치 제외
   기준으로 재산출. `3_10년평균`·`3B_기간별평균`은 이를 참조하는 수식이라 자동 갱신됩니다.
4. **검증표 갱신** — `검증_v03`에 등방성·HDKR × 10년·최근5년 4개 조합 기댓값.
5. **기본 기준 기간 변경** — K5를 `최근5년` → `10년(2016~2025)`으로 되돌렸습니다.
   v02는 계기 편향을 전 지점에 일괄 적용해 회피했지만, v03은 K7이 지점별로 처리하므로
   기본값은 관측 기간이 긴 10년 평균을 씁니다. 웹 기본값과도 일치합니다.

> 산출표는 openpyxl로 편집해 **수식의 캐시값이 비어 있습니다.** Excel에서 열면 자동으로
> 재계산되며 그때 모든 값이 채워집니다. (LibreOffice 재계산은 Rb의 SUMPRODUCT 배열 연산
> 때문에 매우 느립니다.)

## 데이터 갱신

`data/poa.json`은 산출표의 `4_추가분석` 집계에서 생성됩니다.
같은 스키마로 덮어쓰면 사이트 전체가 따라 갱신됩니다.

```
meta   출처·기간·모델·집계규칙·버전
st[]   n(지점명) c(지점코드) lat lon
       ghi[12]  10년 월 유효일평균 GHI (kWh/m²/day, 자료 없으면 null)
       gm[12]   10년 월 합계 GHI      (kWh/m²)
       ghi5[12] gm5[12]  최근 5년 동일 항목
       vm(유효월수) obs(관측연수) yrs(완전관측 연수) cv(연변동)
       br(편향비 최근5년÷2016~19) bv(편향 판정)
```

월 POA는 산출표와 동일하게 `월 GHI × (일평균 POA ÷ 일평균 GHI)`로 계산합니다 —
그래서 `gm`과 `ghi`를 함께 저장합니다.
