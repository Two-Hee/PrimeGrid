# PrimeGrid — 태양광 발전량 성능진단 기준모델

태양광 발전소의 **지역별 일사량 → 경사면 일사량(POA) → 발전량 → 성능진단** 계산 기준을
정의하는 Excel 기준모델입니다. 웹 프로그램(app.py / solar_core.py)과 동일한 계산식을
공유하는 것을 목적으로 합니다.

## 산출물

| 파일 | 설명 |
|---|---|
| `태양광_발전량_성능진단_기준모델_v1.0.xlsx` | 기준모델 워크북 (문서 v1.0 / 모델 MVP-0.2.0) |
| `tools/build_v1_workbook.py` | 위 워크북을 생성하는 스크립트 |

## 워크북 구성 (22개 시트)

| 구분 | 시트 |
|---|---|
| 표지 | `01_표지·목차` — 문서 정보, 요약 지표, 시트 목차(하이퍼링크) |
| 기준문서 | `02_버전이력` `03_모델개요` `04_계산식_명세` `05_FACTOR_기준값` `06_진단규칙` `07_데이터사전` `08_검증CASE` `09_보고서구성` `10_개발연계` |
| 계산모델 | `11_발전량_모델` `12_월별FACTOR` `13_시나리오비교` `14_지역·상수` `15_태양기하` `16_적용한계·참고` |
| 데이터 | `20_원자료` `21_피벗_월별` `22_피벗_연도별` `23_피벗_계절패턴` `24_차트` |
| 보조(숨김) | `_시나리오계산` — `13_시나리오비교`의 SUMIFS 집계용 |

입력 셀은 **노란 배경 + 파란 글씨**, 다른 시트 참조값은 **초록 글씨**, 나머지는 수식 계산값입니다.
사용자가 실제로 입력하는 값은 `11_발전량_모델` 시트 B5:B16 과 `05_FACTOR_기준값` 시트 C열뿐입니다.

## 데이터 출처

기상청 기상자료개방포털 「기후통계분석 - 일조일사」 (<https://data.kma.go.kr/>)
2016년 1월 ~ 2025년 12월, 10개 권역 월별 자료 1,200행. 단위 환산: 1 kWh/m² = 3.6 MJ/m².

## 워크북 재생성

```bash
pip install openpyxl
python tools/build_v1_workbook.py <원본.xlsx> <출력.xlsx>
```

원본 워크북에서는 `원자료` 시트의 실측값만 읽어오며, 나머지 시트는 모두 수식으로 재생성합니다.
생성 후에는 LibreOffice 등으로 재계산하여 수식 오류가 없는지 확인하십시오.

```bash
soffice --headless --convert-to xlsx --outdir <디렉터리> <출력.xlsx>
```

## 적용 한계

광역권 월평균 자료와 지역 대표 위도를 사용하는 **예비 타당성·성능진단용** 모델입니다.
금융·EPC 성능보증·정밀 설계에는 현장 좌표, 시간별 GHI/DNI/DHI 또는 POA 실측,
모듈·인버터 사양과 손실 시뮬레이션을 사용해야 합니다. 자세한 내용은 워크북
`16_적용한계·참고` 시트를 참고하십시오.
