데이터와 계산방법

이 사이트의 모든 수치가 어디에서 나왔는지, 어떤 식으로 계산했는지, 어디까지 믿을 수 있는지를 적어둔 문서입니다.

1. 원자료

출처기상청 기상자료개방포털 ASOS 일사량 관측자료 (합계 일사량)
기간2016-01-01 ~ 2025-12-31 (10년)
자료량일별 관측 177,818건
지점전국 65개소 (이 중 12개월 자료 완비 62개소)
좌표기상청 현재/최신 대표 지점좌표
집계 규칙월 커버리지 80% 이상인 달만 평균 · 일 Kt>1 이상치 27건 제외

월 대표값은 해당 월의 유효 일평균입니다. 관측값이 0인 날(계측 결측으로 판단되는 57건)은 평균에서 제외했습니다. 관측 이력이 짧은 지점은 지점 선택 화면에 부분 자료로 표시하고, 결과에도 참고용임을 명시합니다.

1.1 이상치 제외 (Kt 상한)

일사계에는 이슬·서리·계측 오류로 물리적으로 불가능한 값이 섞입니다. 이를 걸러내기 위해 관측일마다 청명도지수를 계산합니다.

일 Kt = 일 GHI ÷ 그날 그 위도의 대기권외 일사량

대기를 통과한 일사량이 대기권 밖보다 많을 수는 없으므로 Kt > 1은 물리적으로 불가능합니다. 전 관측일 177,818건 중 27건이 여기 해당해 월·연 집계에서 제외했습니다. 최대값은 백령도 2022-10-05의 Kt = 1.69로, 하루 12.6 kWh/m²라는 불가능한 값이었습니다.

Kt 0.85~1.0 구간(139건)은 제외하지 않습니다. 실제로 매우 맑은 날일 수 있어 일괄 제거하면 오히려 값이 왜곡되기 때문입니다. 두 구간 모두 산출표의 3C_이상치검사 시트에 그대로 공개합니다.

제외의 연쇄 효과. 이상치를 빼면 그 달의 관측 커버리지가 함께 떨어집니다. 커버리지가 80% 밑으로 내려간 달은 월평균에서 통째로 빠집니다. 예를 들어 강진군 2018년 12월은 31일 중 7일이 이상치여서 커버리지가 77%가 되었고, 그 달 전체가 평균 대상에서 제외되었습니다. 의도한 동작입니다 — 믿을 수 없는 달은 평균에 넣지 않습니다.

1.2 계기 편향

일사계는 교체·교정 이력에 따라 관측값이 계단식으로 변합니다. 2016~2019년 평균 대비 최근 5년 평균이 15% 이상 높은 지점은 기후 변화가 아니라 계기 편향으로 보고 계기 편향 의심으로 표시합니다. 65개 지점 중 13개가 여기 해당합니다(최대 보성군 +46.7%).

이런 지점에서 10년 평균을 쓰면 현재 조건을 과소평가하게 됩니다. 그래서 기준 기간을 두 단계로 나눠 적용합니다.

대상적용 기준 기간
일반 지점「기준 기간」 설정값 — 기본 10년(2016~2025)
계기 편향 의심 13개 지점「편향 의심 지점 기준기간」 설정값 — 기본 최근 5년(2021~2025)

편향 지점만 최근 5년을 쓰고, 나머지는 관측 기간이 긴 10년 평균을 그대로 씁니다. 두 설정을 같게 두면 전 지점이 동일한 기간을 쓰게 됩니다. 산출표에서는 5_POA_설정 K5·K7이 같은 역할을 하며, 지점별 적용 결과는 6_POA_월계산 AJ·AK열에서 확인할 수 있습니다.

엑셀과 웹의 값이 다르게 보인다면 두 설정이 서로 다른지 먼저 확인하십시오. 기준 기간이 다르면 입력 GHI가 달라지고, 그에 따라 Kt·확산분율·POA가 모두 달라집니다. 계산식 자체는 양쪽이 동일합니다.

2. 계산식

수평면 일사량(GHI)을 경사면 일사량(POA)으로 변환합니다. 순서는 다음과 같습니다.

2.1 태양기하

단계식
연중각B = 2π(n−1)/365, n = 월 대표일 DOY
지구–태양거리E₀ = 1.000110 + 0.034221cosB + 0.001280sinB + 0.000719cos2B + 0.000077sin2B
태양적위δ = 0.006918 − 0.399912cosB + 0.070257sinB − 0.006758cos2B + 0.000907sin2B − 0.002697cos3B + 0.001480sin3B
일몰시각각ωs = acos(−tanφ·tanδ)
대기권외 일사량H₀ = (24·60/π)·Gsc·E₀·[cosφ cosδ sinωs + ωs sinφ sinδ]

Gsc = 0.0820 MJ/m²/min. H₀는 MJ/m²/day로 나오므로 3.6으로 나누어 kWh/m²/day로 변환합니다. 이 단위 변환을 빠뜨리면 청명도지수 Kt가 실제의 약 1/3.6로 계산되어 확산분율이 완전히 어긋납니다.

월 대표일(DOY)은 Klein의 월평균 대표일을 씁니다: 17, 47, 75, 105, 135, 162, 198, 228, 258, 288, 318, 344

2.2 직달·산란 분리

Kt = H / H₀

확산분율은 Erbs 월평균 상관식을 씁니다. 일별 상관식이 아닙니다 — 입력이 월평균 일사량이므로 월평균용 계수를 써야 합니다.

조건Hd/H
ωs ≤ 81.4°1.391 − 3.560Kt + 4.189Kt² − 2.137Kt³
ωs > 81.4°1.311 − 3.022Kt + 3.427Kt² − 1.821Kt³

적용범위는 Kt 0.30~0.80입니다. 이 범위를 벗어난 달은 도구의 월별 표에 범위외로 표시합니다.

2.3 직달 기하계수 Rb

하루를 15분 96구간으로 나누고, 태양고도가 양수인 구간만 적분합니다.

SunU = sinφ sinδ + cosφ cosδ cosω
SunE = −cosδ sinω
SunN = sinδ cosφ − cosδ sinφ cosω

모듈 법선벡터는 방위각 A(북 0° / 동 90° / 남 180° / 서 270°) 기준으로

nE = sinβ sinA, nN = sinβ cosA, nU = cosβ

cos(AOI) = SunEnE + SunNnN + SunUnU
Rb = Σ max(cos AOI, 0) / Σ SunU

2.4 경사면 일사량 합산

POA = Hb·Rb + Hd·(1+cosβ)/2 + H·ρg·(1−cosβ)/2

차례로 직달, 등방성 천공산란, 등방성 지면반사입니다. 등방성(Liu–Jordan) 모델은 단순하고 투명하지만 원일광(circumsolar)과 수평선 밝기를 반영하지 않아 맑은 날 경사면 일사량을 다소 낮게 봅니다. 이방성 모델(HDKR)로 계산하면 연간 평균 +3.24%(지점별 +2.3~+3.5%) 높게 나옵니다. 이 사이트는 보수적인 쪽인 등방성 값을 기본으로 씁니다. 산출표에서는 5_POA_설정의 천공 모델을 HDKR로 바꿔 두 값을 비교할 수 있습니다.

2.5 발전량

발전량 = 설비용량(kWdc) × POA(kWh/m²) × PR × 모듈 성능계수

1년차 성능계수 = 1 − 초기저하율
n년차 성능계수 = (1 − 초기저하율) × (1 − 연간저하율)(n−1)

기본값은 초기 1.5%, 연 0.33%입니다. 모듈 보증서의 값으로 바꿔 쓰십시오.

3.2 물리 검산 — β = 0°

경사각을 0°로 두면 Rb = 1, 천공 view factor = 1, 지면 view factor = 0이 되어 POA와 GHI가 정확히 같아야 합니다. 전 지점에서 오차 0으로 성립합니다.

4. 불확실성

예상 발전량은 단일 값이 아니라 분포입니다. 두 가지 불확실성을 독립으로 보고 합성합니다.

  • 기후 연변동 — 해가 바뀌면 일사량이 달라집니다. 지점별로 완전 관측된 해들의 연간 일사량 표준편차를 그대로 씁니다. 전국 중앙값은 ±3.7%입니다.
  • 모델 불확실성 — 월평균 기후값 + Erbs + 등방성 조합의 구조적 오차로 ±5%를 잡습니다.

σ = √(σ기후² + σ모델²), P90 = P50 × (1 − 1.282σ), P75 = P50 × (1 − 0.674σ)

P50은 절반의 해가 밑도는 값입니다. 금융 검토라면 P90을 함께 보십시오.

5. 한계 — 계산에 들어있지 않은 것

  • 음영 — 지평선, 주변 건물·산지, 모듈 열간 상호음영 모두 미반영
  • 오염·적설 — 모듈 표면 상태에 따른 손실 미반영
  • 모듈 온도 — 여름철 출력 저하는 PR에 뭉뚱그려져 있을 뿐 별도 모델 없음
  • 입사각 손실(IAM) — 유리면 반사 손실 미반영
  • 계통 출력제한 — curtailment 미반영
  • 특정 연도 — 월평균 기후값 기반이므로 "2024년 발전량"을 맞히지 못합니다
  • 추적식 — 고정식 모듈 전제. 추적식에는 적용 불가
  • 지점–현장 거리 — 관측지점과 발전소가 멀수록 오차가 커집니다

이 항목들은 실제 발전량을 낮추는 방향으로 작용합니다. 따라서 도구가 내놓는 기준선은 이상적인 조건에서의 상한에 가까운 값으로 읽는 것이 안전합니다. 진단 결과가 기준선을 조금 밑도는 것은 흔한 일입니다.

6. 이용 조건
