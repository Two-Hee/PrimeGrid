# 종목 뉴스 브리핑

종목명·종목코드·티커와 기간을 입력하면 관련 뉴스를 모아 **PDF 브리핑**으로 만들어 주는 웹앱.
**가입·API 키·직접 운영하는 서버가 전혀 필요 없다.** 주소만 열면 바로 쓴다.

```
https://two-hee.github.io/PrimeGrid/newsbrief/
```

## 바탕화면에 앱으로 추가

브라우저가 아니라 앱처럼(주소창 없이 전체 화면) 실행된다. 앱스토어 설치가 아니라 웹앱 등록이다.

- **아이폰(Safari)** : 화면 아래 가운데 **공유 버튼(□ 위로 화살표)** → 목록을 내려 **홈 화면에 추가**
- **안드로이드(Chrome)** : 처음 열 때 뜨는 배너의 **추가** 버튼 (또는 ⋮ → 앱 설치)
- **PC(Chrome·Edge)** : 주소창 오른쪽 **설치 아이콘** 클릭

서비스 워커가 화면과 PDF 라이브러리를 저장해 두므로, 네트워크가 끊겨도 앱 자체는 열린다.
(뉴스를 새로 받아오는 것은 당연히 인터넷이 필요하다)

## 사용법

1. **종목** — 아래 네 가지 중 아무거나 입력. 목록에 없는 이름·티커도 그대로 검색된다.

   | 입력 예 | 인식 |
   |---|---|
   | `삼성전자` | 국내 · 005930 |
   | `005930` | 국내 |
   | `애플` 또는 `AAPL` | 해외 · Apple |
   | `NVDA` | 해외 |

2. **기간** — 오늘 / 3일 / 1주일 / 1개월 / 3개월, 또는 **직접 지정**으로 시작일~종료일 선택
3. **뉴스 수집 & 브리핑 만들기**
4. **📄 PDF 다운로드** — 그대로 저장·공유·인쇄할 수 있는 A4 문서가 만들어진다
   (원문 링크를 눌러 기사로 이동하고 싶으면 **HTML** 저장을 쓴다)

주소에 조건을 담아 실행할 수도 있다. 자주 보는 종목은 이 주소를 즐겨찾기 해 두면 편하다.

```
.../newsbrief/?q=삼성전자&d=7&auto=1          열자마자 1주일치 자동 수집
.../newsbrief/?q=AAPL&from=2026-07-01&to=2026-07-26
```

## 브리핑에 담기는 내용

- 종목명·코드·국내/해외 구분, 수집기간, 작성시각, 출처, 수집 건수
- 전체 / 호재 / 악재 / 중립 건수
- **카테고리 5종 + 기타** — 실적·공시 · 수주·계약 · 규제·정책 · 증권사 리포트 · 리스크
- 카테고리별 기사 목록. 기사마다 **톤 배지 · 제목 · 2~3줄 요약 · 언론사 · 발행일시 · 원문 링크**

원문 전문은 저장하지 않는다. 언론사가 스스로 공개한 요약문(`og:description`)을 2~3문장까지만
가져오고, 제목·링크·발행시각과 함께 수록한다.

## 뉴스는 어디서 오나

| 경로 | 대상 | 얻는 것 |
|---|---|---|
| 구글 뉴스 RSS (한국어·영어) | 국내·해외 전 종목 | 제목, 언론사, 발행시각, 링크 |
| 네이버 금융 종목뉴스 | 국내 6자리 종목코드 | 국내 매체 기사 보강 |
| 각 기사 페이지의 요약문 | 상위 N건 (기본 16건) | 2~3줄 요약 |

브라우저는 보안 정책(CORS) 때문에 다른 사이트를 직접 읽지 못한다. 그래서 **가입이 필요 없는
공개 중계 서비스**를 거쳐 가져오며, 한 곳이 막히면 자동으로 다음 곳을 시도한다(총 4곳).
사용자가 뭔가를 설치하거나 키를 발급받을 일은 없다.

## 알아둘 점

- **호재/악재와 카테고리는 제목·요약문의 키워드에 따른 기계적 분류**다. 실제 기사 내용과 다를 수 있으니
  판단 전에 반드시 원문을 확인해야 한다. 본문을 읽고 이해해서 쓰는 요약(LLM 요약)은 들어 있지 않다.
- 공개 중계 서비스는 무료로 운영되는 곳이라 간헐적으로 느리거나 실패할 수 있다.
  네 곳이 모두 막히면 잠시 후 다시 시도하면 된다.
- 네이버 금융 종목뉴스는 화면 구조가 바뀌면 수집이 실패할 수 있다. 실패해도 구글 뉴스 결과로 브리핑은 만들어지고,
  화면에 어떤 경로가 실패했는지 표시된다.
- 기사 저작권은 각 언론사에 있다. 본 자료는 참고용이며 투자 판단의 근거로 사용할 수 없다.

## 파일 구조

```
newsbrief/
├─ index.html               앱 전체 (화면 · 수집 · 분류 · PDF)
├─ manifest.webmanifest     홈 화면 앱 설정
├─ sw.js                    서비스 워커 (오프라인 실행)
├─ icons/                   앱 아이콘 · 아이폰 실행 화면
└─ lib/
   ├─ jspdf.umd.min.js      PDF 생성 (MIT)
   └─ html2canvas.min.js    화면 → 이미지 변환 (MIT)
```

외부 CDN을 쓰지 않고 라이브러리를 저장소에 함께 둔다. 오프라인에서도 PDF가 만들어지고,
외부 서비스가 사라져도 앱이 깨지지 않는다.
