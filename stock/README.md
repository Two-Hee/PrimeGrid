# 종목 뉴스 브리핑 (휴대폰용)

종목명 또는 종목코드와 검색 기간을 입력하면 관련 뉴스를 모아
브리핑 파일(HTML / 텍스트 / PDF)로 만들어 주는 단일 파일 웹앱.

| 파일 | 뉴스 출처 | 준비물 |
|---|---|---|
| `naver_news_briefing.html` | **네이버 뉴스 검색 API** (권장) | 네이버 API 키 + 중계 서버 1회 배포 |
| `news_briefing.html` | 구글 뉴스 RSS | 없음 (공개 중계 서버 경유, 가끔 끊김) |

---

## 1. 실행 방법 (휴대폰)

### 방법 A — GitHub Pages (권장)

이 저장소는 Pages가 켜져 있고 기본 브랜치는 `main`이다.
**파일이 `main`에 있어야 주소가 열린다.** 브랜치에만 있으면 404가 난다.

```
https://two-hee.github.io/PrimeGrid/stock/naver_news_briefing.html
https://two-hee.github.io/PrimeGrid/stock/news_briefing.html
```

### 방법 B — 브랜치 상태 그대로 미리 보기

`main` 병합 전에 확인하고 싶을 때. GitHub의 `raw` 주소는 HTML이 코드로만 보이므로
아래 미리보기 서비스를 쓴다.

```
https://raw.githack.com/Two-Hee/PrimeGrid/<브랜치명>/stock/naver_news_briefing.html
```

### 홈 화면에 앱처럼 등록하기 (설치 아님)

위 주소를 휴대폰 브라우저로 연 뒤,

- **아이폰(Safari)** : 화면 아래 가운데 **공유 버튼(□ 위로 화살표)** → 목록을 아래로 내려
  **‘홈 화면에 추가’** → 오른쪽 위 **추가**
- **안드로이드(Chrome)** : 오른쪽 위 **⋮** → **‘홈 화면에 추가’**

홈 화면에 아이콘이 생기고, 주소창 없이 전체 화면으로 실행된다.

## 2. 네이버 API 버전 설치 (약 5분, 전부 무료)

네이버 뉴스 API는 `Client Secret`이 필요해 **휴대폰에서 직접 호출할 수 없다.**
(응답에 CORS 헤더가 없어 브라우저가 막고, HTML에 키를 넣으면 그대로 노출된다)
그래서 키를 숨긴 채 대신 호출해 주는 **중계 서버**를 한 번만 배포한다.

### 2-1. 네이버 API 키 발급

1. <https://developers.naver.com/apps/#/register> 접속 → 네이버 로그인
2. **애플리케이션 이름** 아무거나 입력
3. **사용 API** → `검색` 선택
4. **비로그인 오픈 API 서비스 환경** → `WEB 설정` 추가 → URL은 아무 값이나 (예: `https://two-hee.github.io`)
5. 등록하면 **Client ID / Client Secret** 이 나온다 → 복사해 둔다

> 무료 한도: 하루 25,000회. 이 앱은 검색 1회에 1~4회 정도 쓴다.

### 2-2. Cloudflare Workers에 중계 서버 배포

1. <https://dash.cloudflare.com> 가입 (무료, 카드 등록 불필요)
2. 좌측 **Workers & Pages** → **Create** → **Start with Hello World!** → **Deploy**
3. 배포된 워커에서 **Edit code** → 기존 코드를 모두 지우고
   이 저장소의 **`stock/proxy/cloudflare-worker.js`** 내용을 붙여넣기 → **Deploy**
4. 워커 화면의 **Settings → Variables and Secrets** 에서 **Secret** 두 개 추가
   - `NAVER_CLIENT_ID` = 발급받은 Client ID
   - `NAVER_CLIENT_SECRET` = 발급받은 Client Secret
   - 저장 후 다시 **Deploy**
5. 워커 주소를 복사한다 → `https://<이름>.<계정>.workers.dev`

> 특정 사이트에서만 쓰게 잠그려면 일반 변수로 `ALLOW_ORIGIN` 에
> `https://two-hee.github.io` 를 넣으면 된다. (미설정 시 모든 출처 허용)

### 2-3. 앱에 연결

1. 휴대폰에서 `naver_news_briefing.html` 을 연다
2. 맨 위 **API 설정** 칸에 워커 주소를 붙여넣는다
3. **연결 테스트** → `✓ 연결 정상` 이 뜨면 끝

주소는 그 기기의 브라우저에만 저장되고, 다음부터 설정 칸은 자동으로 접힌다.

### 2-4. (선택) PC에서 먼저 확인

```bash
NAVER_CLIENT_ID=발급받은아이디 NAVER_CLIENT_SECRET=발급받은시크릿 \
  node stock/proxy/local-server.js
# → http://localhost:8787 을 앱의 [API 설정] 칸에 입력
```

## 3. 사용법

1. **종목명 또는 6자리 종목코드** 입력 (주요 120종목 자동완성, 목록에 없는 종목도 입력 가능)
2. **검색 기간** — 오늘 / 3일 / 1주일 / 1개월 / 3개월 버튼, 또는 **직접 지정**으로 시작일~종료일 선택
3. **뉴스 수집 & 브리핑 만들기**
4. 화면 아래 버튼으로 저장
   - **💾 브리핑 저장** — 표·통계가 들어간 완성형 HTML 파일
   - **📄 텍스트 저장** — 메신저·메일에 붙여 넣기 좋은 형태
   - **📤 공유** — 카톡·메일 등으로 파일 바로 전송
   - **🖨 인쇄** — 브라우저 인쇄 화면에서 **PDF로 저장** 선택

### 고급 설정

| 항목 | 설명 |
|---|---|
| 관련 키워드 확장 검색 | 종목명 단독 검색에 더해 실적·공시·수주·목표주가 등을 붙여 한 번 더 검색 |
| 제목·본문에 종목명 포함된 기사만 | 동명이인·업계 일반 기사 제외 (네이버 버전) |
| 중복·전재 기사 제거 | 같은 기사를 여러 매체가 받아쓴 경우 1건으로 정리 |
| 최대 수집 건수 | 30 / 50 / 100 / 200건 |

## 4. 브리핑에 담기는 내용

- 종목명·코드·분석기간·작성시각
- 전체 / 호재 / 악재 / 중립 건수
- 일자별 기사량 추이
- 이슈 분포 — 실적 · 공시·지배구조 · 수주·계약 · 신사업·투자 · 증권가·목표주가 · 정책·규제 · 시황·수급 · 리스크·소송
- 핵심 키워드 Top 10
- 주요 언론사 분포 (네이버 버전)
- 날짜별 기사 타임라인 — 제목 · 요약문 · 언론사 · 발행시각 · 원문 링크

---

## 5. 알아둘 점

- **호재/악재 판정은 제목·요약문의 키워드 매칭에 의한 기계적 분류**로, 실제 기사 내용과 다를 수 있다.
  본문을 읽고 요약하는 기능(LLM 요약)은 들어 있지 않다.
- 네이버 뉴스 검색 API는 **기간 지정 파라미터가 없어서**, 최신순으로 페이지를 넘겨 받아
  앱에서 기간을 잘라낸다. 질의당 최대 1,000건까지 조회 가능하므로
  기사가 아주 많은 종목의 3개월치는 일부만 수집될 수 있다.
- 기사 저작권은 각 언론사에 있다. 이 도구는 제목·요약문·링크·발행시각만 다루며 본문을 저장하지 않는다.
- 본 자료는 참고용이며 투자 판단의 근거로 사용할 수 없다.
